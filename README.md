# 냉난방공조 허브 (HVAC Hub)

냉난방공조 설비 현장과 설계를 위한 무료 계산기 사이트입니다. GitHub Pages 정적 사이트로, 모든 계산은 브라우저 안에서 처리됩니다.

- **라이브 주소:** https://hvaccalc.github.io/
- **기준:** KS 기준, 건축설비 설계 기준, 서울 설계 외기온도(겨울 -11°C, 여름 32°C)
- **언어:** 한국어

## 계산기 5종

1. **냉방부하** — 면적과 용도, 인원, 기기 발열, 창 면적으로 필요 냉방능력을 kW와 RT로 계산합니다.
2. **난방부하** — 외피 손실과 환기 손실을 합산해 난방부하와 보일러 용량을 계산합니다.
3. **덕트 풍량·풍속** — 풍량과 덕트 치수로 풍속을 계산하고 기준에 맞는지 판정합니다.
4. **환기량·환기횟수** — 체적 기준과 인원 기준 중 큰 값으로 필요 환기량을 계산합니다.
5. **냉매배관·냉동능력** — 냉동능력과 배관 길이로 액관·가스관 규격과 추가 냉매 충진량을 계산합니다.

## 실무 가이드 6편

- 에어컨 설치 실무
- 덕트 설계 기초
- 냉매 충전과 누설 점검
- 결로 대책
- 필터와 열교환기 관리
- VRF 시스템 이해

모든 가이드는 `guides/` 폴더의 독립 페이지로 열립니다.

## 면책

모든 계산 결과는 참고용 추정치입니다. 실제 설계에서는 기기 제조사의 자료, 최신 건축설비 기준과 실내공기질 관련 법규를 확인하고 자격을 갖춘 설비기술자의 판단에 따라야 합니다.
